# NIFTY Paper Research

This repository collects forward paper estimates only. No real trading is enabled.

- [Existing Time And Delta Based Straddles](ROLLING_STRATEGIES.md): three families including Fixed Entry across Current Week, Next Week and Monthly expiries, each with nine independent stop levels.
- [Short Strangle Paper Research](short_strangle/README.md): independent project module and workflow; frozen 09:30 spot, 1%/1.5%/2% distances, nearest-100 strikes, three expiries, nine independent stops, 15:00 exit and no re-entry. Two dedicated tabs in the existing workbook.

Paper threshold stop fills are assumptions. Missing data is not zero profit; unhedged shorts have no guaranteed loss cap. See each project's documentation for evidence, costs, coverage and automation constraints.
