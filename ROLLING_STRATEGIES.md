# Time Based and Delta Based paper challengers

Forward-only start: 29 October 2026. Existing Fixed Entry collectors and history are unchanged. Never place real broker orders. Every family has Current Week, Next Week and Monthly selectors. Exact contract symbols come from FYERS master and expiry metadata. Include actual expiry day; Next Week means one listed expiry after Current Week. Monthly uses actual futures expiry cross-verified in option metadata.

Common rules: nearest 50-point ATM, 65 units per leg, 09:30 entry (09:35 latest), independent 10/15/20/25/30/35/40/45/50% stops, threshold paper fills, 15:00 final exit. Each SL scenario owns its own independent cycle history. New entries reset both stops. Rs150 combined round-trip assumed cost per cycle, maximum Rs450 for three cycles. Rs250000 capital is a comparison base, not guaranteed adequate margin. Quotes, Greeks, actual capture times and missed windows must not be backdated.

Time Based resets at 11:20 and 13:10 (maximum 30-second grace). Close surviving legs, then enter the current ATM even if strike unchanged or both prior legs stopped. A missed reset marks the day INCOMPLETE rather than inventing prices. Three entries maximum.

Delta Based records reference D=-deltaCE-deltaPE at each cycle entry, without lot/quantity multiplication. Monitor signal D from BOTH original contracts of the active cycle, including any contract whose paper position has already stopped out. This hypothetical original-pair delta differs from actual open-position delta. Trigger strictly abs(D-current_reference)>0.35, not >=0.35. Close survivors only (never close a stopped leg again) and enter current ATM with a new reference, up to two rolls / three entries total. Require finite fresh Greeks and a replacement ATM pair with smaller absolute net delta before resetting. If both legs are flat, do not re-enter. A stop itself does not remove that contract from the delta signal; after the entry limit, maintain original SLs through 15:00.

One shared rolling collector handles six paper studies. It uses a shared quote socket, per-expiry option chains in rotation (one request every five seconds; normally each expiry every15seconds), and isolated per-scenario state. This is sampled delta monitoring, not tick-by-tick Greeks. Missing/stale Greeks for either original contract suppress rolls; serious coverage gaps mark days INCOMPLETE, excluded from completed returns. On restart, existing current-day rows block automatic re-entry; inspect state artifact rather than blindly resuming partial positions. Workflow concurrency prevents overlapping rolling runs. This does not reserve FYERS quota against external scripts.

GitHub schedules are best effort. User can start the new Rolling Straddles workflow at09:10IST if absent, with setup_only=false; never duplicate queued/running sessions. Scheduled startup alone cannot guarantee09:30. Monitor first-session evidence, fresh FYERS credentials and Sheet permissions. No historical reconstruction is requested. No first live paper session is claimed by static tests.

Entries and resets require quote-socket prices received within ten seconds, not option-chain LTP fallback. Greeks are option-chain model snapshots sampled approximately every15seconds; their exchange/model timestamp is not exposed, so freshness beyond response receipt cannot be independently verified. Logs must be interpreted as sampled paper estimates, not executable fills. Normal launch is restricted to the single concurrency-protected GitHub workflow.


## Delta cycle audit fields

Delta log rows are published from the first successful entry checkpoint, using the stable date/family/expiry-choice/SL/cycle Event ID. The same row is updated after stops, a roll, or final exit; retries never append another copy of that event. Entry Time records the actual capture time and Reference Delta is the original CE+PE short-pair delta at that cycle entry. Close Time is the outgoing cycle close time; when either leg exit reason is DELTA RESET it is the roll time. Close Delta is the outgoing original pair signal at that roll, including a stopped contract, and Delta Changed is its absolute change from Reference Delta. The following cycle row carries the new ATM entry/reference. Final session exits are not labelled as rolls, and absent final-exit Greeks remain blank rather than inferred. Open-leg exit prices and unsettled cycle net P&L stay blank until observed; a stopped leg retains its original fill and exit time. Time Based and Fixed Entry trading rules are unchanged.
